# NestFinance

Backend-сервіс для ведення особистих фінансів: доходи, витрати, рахунки та базова аналітика. Побудований на Nest.js.

## Опис

**NestFinance** — це API для трекінгу особистих фінансів з підтримкою різних типів рахунків та транзакцій.  
Ціль — мати зручний бекенд, який можна підключити до веб чи мобільного клієнта, а також потенційно інтегрувати з банківськими API (Monobank, PrivatBank тощо).

## Основний функціонал (MVP)

- 🔐 **Авторизація та аутентифікація**
    - Реєстрація / логін користувача
    - Захищений доступ до даних користувача

- 💳 **Рахунки (Accounts)**
    - Типи: банківські рахунки, крипта, кредитні картки, акції тощо
    - Створення / перегляд списку рахунків

- 💰 **Транзакції (Transactions)**
    - Доходи / витрати
    - Базовий та оптимізований розрахунок балансу по рахунках

## У планах

- 🔁 **Тип транзакцій: переказ (transfer)**
    - Переказ між власними рахунками з коректним перерахунком балансу

- 🧾 **Конверти, борги, збереження**
    - Віртуальні "конверти" / категорії
    - Облік боргів
    - Фічі для збережень

- 📊 **Звітність**
    - Звіт за вказаний період (доходи/витрати, по категоріях, по рахунках)

- 🏦 **Інтеграції (idea)**
    - Monobank API
    - PrivatBank API

## Технології

- [NestJS](https://nestjs.com/) (Node.js framework)
- TypeScript
- REST API
- PostgreSQL + TypeORM
